# tutor-examen

Tutor para preparar un examen de la facultad de cualquier materia. Lee la carpeta de la materia (programa, diapositivas, guías, libros, modelos de examen), entiende cómo es la cátedra y qué evalúa, pregunta lo que falta, toma un diagnóstico y arma un plan de trabajo hasta el día del examen. Después lo lleva sesión a sesión con parrillas de preguntas, lecturas exactas del libro, ejercicios para resolver a mano y prácticas de laboratorio, y guarda todo en la carpeta `_tutor/` de la materia.

Para instalarlo:

```
claude plugin marketplace add marino-san/skill-aprobar-examen
claude plugin install tutor-examen@skill-aprobar-examen
```

Las instrucciones del tutor están en [skills/tutor-examen/SKILL.md](skills/tutor-examen/SKILL.md). Cómo usarlo y actualizarlo está en el [README del repo](../../README.md).
